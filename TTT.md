# Trouble in Tee Town

The classic "Trouble in Terorrist Town" game for Teeworlds.

There must be a pre-lobby that contains map vote / selection and a 'ready' / waiting phase for players to join.

### Actual Game

At game start, 1/3rd of players are selected as terrorists, and one of the non-terrorists are selected as a detective. There is a 30 second introductory period where pvp among all members is disabled. Weapons are spawned in around the map as single pick-upable entities. Only pistol (gun), shotgun, grenade, and laser spawn. (Players start with only hammer). Weapon pickups only give 5 ammo, so a player would have to pick up two of the same weapon to get 10 total ammo.

After grace period is over, pvp is enabled among everyone. The last party standing (innocents vs terrorists) win.
